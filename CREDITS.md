# Credits

## Sound effects

The sampled effects in `assets/sfx/` come from [Mixkit](https://mixkit.co/free-sound-effects/)
and are used under the Mixkit Free License (free for commercial and personal
projects, no attribution required):

| File | Source |
| --- | --- |
| `eat.mp3` | https://mixkit.co/free-sound-effects/pop/ (asset 2354) |
| `bomb.mp3` | https://mixkit.co/free-sound-effects/explosion/ (asset 1278) |
| `crash.mp3` | https://mixkit.co/free-sound-effects/impact/ (asset 1143) |
| `win.mp3` | https://mixkit.co/free-sound-effects/win/ (asset 1928) |

The game still synthesises its other effects (gift drops, speed, slow, error,
clicks) with Web Audio, so it works with no assets at all.
